# پنل مدیریت سایت هلیله

## نصب (یک‌بار)
1. در سی‌پنل → File Manager → `public_html` → Upload → فایل `helileh-cms.zip` → روی آن راست‌کلیک → Extract.
   (اگر پرسید فایل‌ها جایگزین شوند، بله؛ `.htaccess` و `contact.php` به‌روز می‌شوند.)
2. سی‌پنل → Select PHP Version → Extensions: `pdo_sqlite`, `sqlite3`, `mbstring`, `fileinfo`, `gd`, `dom` تیک داشته باشند.
3. مرورگر: `https://heleyleh-bu.ir/install.php` → نام، نام‌کاربری و رمز مدیر (حداقل ۱۰ نویسه) → «ساخت مدیر و نصب».
4. **فایل `install.php` را از public_html حذف کنید.**
5. ورود: `https://heleyleh-bu.ir/admin/`

دیتابیس در پوشه `cms_data` (بالاتر از public_html، در صورت امکان) ذخیره می‌شود؛ از آن بک‌آپ بگیرید. عکس‌ها در `public_html/uploads`.

## کار با پنل
- **نوشته‌ها / محصولات / رویدادها / اقامتگاه‌ها / گالری**: هر مورد سه تب زبان (فارسی، English، Русский) دارد؛ زبانی که عنوانش خالی باشد در همان زبان نمایش داده نمی‌شود.
- **صفحات**: متن بالای صفحه‌های سایت (درباره، اقامت، تجربه‌ها، …) را جایگزین می‌کند؛ لیست‌ها خودکار زیرش می‌آید.
- **کتابخانه رسانه**: آپلود چندتایی، بهینه‌سازی خودکار، متن جایگزین سه‌زبانه. داخل ویرایشگر هم دکمه «🖼 تصویر» دارید.
- **پیام‌ها**: پیام فرم تماس و درخواست‌های سفارش/رزرو (علاوه بر ایمیل) اینجا ذخیره می‌شود.
- **کاربران**: مدیر کل، ویراستار، مدیر فروشگاه و اقامت، نویسنده (نویسنده فقط پیش‌نویس/در انتظار بازبینی می‌فرستد).
- نشانی هر مورد: `/blog/نام/`، `/handicraft-shop/نام/`، `/events/نام/`، `/accommodations/نام/` (در انگلیسی و روسی با پیشوند و اسلاگ همان زبان).
- نقشه سایت موردهای جدید: `https://heleyleh-bu.ir/sitemap-cms.xml` (در Search Console ثبت کنید).

## تجربه‌ها و مجری‌ها (صفحهٔ «تجربه‌ها و آدم‌هایش»)
از منوی پنل: **تجربه‌ها** و **مجری‌های تجربه‌ها**. کارت‌ها دقیقاً با همان قالب، آیکن‌های متحرک و استایل فعلی سایت نمایش داده می‌شوند.
- **مجری**: نام، شماره تماس (ارقام فارسی هم پذیرفته می‌شود)، عکس (از کتابخانه رسانه؛ در سایت دایره‌ای نمایش داده می‌شود).
- **تجربه**: نام، یکی از ۱۲ آیکن سایت، مجری‌ها (چندتایی؛ بدون مجری ⇒ «آزاد؛ بدون نیاز به هماهنگی»)، عدد ترتیب (کوچک‌تر ⇒ بالاتر)، وضعیت (منتشرشده/پیش‌نویس).
- **اولین بار**: در فهرست «تجربه‌ها» دکمهٔ «وارد کردن داده‌های فعلی» ۱۲ تجربه و ۱۰ مجری فعلی سایت را وارد پنل می‌کند (ظاهر سایت تغییر نمی‌کند). تا وقتی چیزی در پنل منتشر نشده، سایت همان فهرست ثابت قبلی را نشان می‌دهد.
- حذف مجری‌ای که در تجربه‌ای انتخاب شده مسدود است (وگرنه آن تجربه «آزاد» نشان داده می‌شد)؛ اول او را از تجربه‌ها بردارید.
- نوار «تجربه‌ها» در صفحهٔ اصلی انگلیسی/روسی (و فارسی، وقتی از حالت به‌روزرسانی خارج شود) هم از همین پنل می‌آید؛ هر مشکلی پیش بیاید همان صفحهٔ استاتیک نمایش داده می‌شود.
- آیکن‌ها از `xp-icons.json` خوانده می‌شوند که هنگام build سایت از همان کامپوننت React ساخته می‌شود (پس بعد از اولین دیپلوی این نسخه موجود است).

### ترجمهٔ خودکار
فقط نام فارسی را بنویسید؛ هنگام ذخیره، نام انگلیسی و روسی (اگر خالی باشند) خودکار ترجمه می‌شود و می‌توانید دستی اصلاحشان کنید. گزینهٔ «ترجمهٔ مجدد» متن‌های موجود را دوباره از فارسی می‌سازد.
سرویس از **تنظیمات ← ترجمهٔ خودکار** انتخاب می‌شود (MyMemory بدون کلید، LibreTranslate، Google Cloud Translation) و دکمهٔ «آزمایش ترجمه» کار کردنش را از روی همین هاست نشان می‌دهد. هاست باید HTTPS خروجی (curl) داشته باشد؛ اگر سرویس در دسترس نباشد، ذخیره انجام می‌شود، پیغام خطا می‌آید و تا ورود ترجمهٔ دستی، متن فارسی نمایش داده می‌شود. نام آدم‌ها را بعد از ترجمهٔ خودکار حتماً بازبینی کنید.

## امنیت
رمزها با bcrypt، توکن CSRF روی همه فرم‌ها، کوکی HttpOnly/SameSite، محدودیت تلاش ورود، پاک‌سازی HTML ورودی، آپلود فقط تصویر با بررسی محتوا، اجرای PHP در uploads غیرفعال، و دسترسی وب به cms-core بسته است.
